# Die Werkbank – Design

Private Statistikseite für die fünf Spieler von Create Survival.
Recherche: https://skills.sh/anthropics/skills/frontend-design und
https://mcscore.app/stats/ (Spielersuche, Profile, Ranglisten), außerdem
https://mcanalytics.org/demo/players (Datenstand und klare Statistikdefinitionen).
Die Seiten dienen der Orientierung; kein fremdes Layout oder Quellcode übernommen.

Palette: Tiefenschiefer #111b24, Werkstattschiefer #192833, Text #e9f0ed,
Mint #81d8bd, Kupfer #dbac7c, Sekundärtext #9aadb4.
Typografie: lokal gehostete Space Grotesk für Überschriften, lokal gehostete
DM Sans für Oberfläche und Zahlen. Geordnete, linksbündige Tabellen; keine
komplette Minecraft-Pixelschrift für Fließtext.

Desktop: feste schmale Navigation, Inhaltsfläche mit einer eigenen isometrischen
Fabrikillustration. Darunter dominierende Rangliste neben kompakten Weltrekorden.
Mobil: horizontale Navigation, eine Spalte, bequem bedienbare Filter.
Ein Minecraft-Bezug entsteht durch eigene Voxelillustration, pixelige Avatare und
Werkstattfarben. Unterschiedliche Flächenhierarchie statt identischer Karten.

Daten werden nicht erfunden. Gesamtwerte seit Weltstart, Zeitraumwerte erst seit
Beginn der lokalen Aufzeichnung. Item-Nutzung nicht als Blockplatzierung bezeichnen.
Keine externen Fonts, Tracker oder Avatarabrufe im Browser. Tastaturbedienung,
Kontrast, kleine Displays und reduzierte Bewegung berücksichtigen.
